# SQL-ASSISTENTE-I.A

## Sobre o projeto

O **SQL-ASSISTENTE-I.A** é um projeto pessoal em desenvolvimento que tem como objetivo criar um assistente de Inteligência Artificial voltado para auxiliar estudantes no aprendizado de SQL, com foco em SQL Server e T-SQL.

A proposta é desenvolver uma aplicação web interativa capaz de explicar conceitos, apresentar exemplos de consultas e ajudar o usuário a compreender a lógica por trás dos comandos SQL, incentivando o aprendizado prático e a autonomia nos estudos.

## Objetivos

- Desenvolver uma aplicação web interativa.
- Auxiliar no aprendizado de SQL e SQL Server.
- Ajudar desde iniciantes até quem já pratica algum tempo e enfrenta problemas complexos utilizando T-SQL.

## Tecnologias e ferramentas previstas

- **Python:** linguagem principal para o desenvolvimento da aplicação.
- **Streamlit:** criação da interface web interativa.
- **Groq API:** integração com modelos de linguagem para geração de respostas.
- **Visual Studio Code (VS Code):** ambiente de desenvolvimento.
- **Git e GitHub:** versionamento de código, gerenciamento do histórico de alterações e documentação do projeto.

Outras bibliotecas poderão ser adicionadas conforme a evolução do projeto.

## Funcionamento proposto

1. O usuário envia uma pergunta ou dúvida sobre SQL.
2. A aplicação desenvolvida em Python recebe a pergunta.
3. A pergunta é enviada à API da Groq, que fornece acesso ao modelo de linguagem configurado.
4. O modelo gera uma resposta com explicações e exemplos.
5. A aplicação apresenta a resposta ao usuário por meio de uma interface web.

## Público-alvo

Estudantes de tecnologia, iniciantes em bancos de dados e pessoas que desejam desenvolver seus conhecimentos em SQL e SQL Server.
